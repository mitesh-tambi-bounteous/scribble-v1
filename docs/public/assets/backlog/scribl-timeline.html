scribl -- Timeline, milestones and capacity

Project: scribl. Status: draft for team review. Updated: 2026-08-20. Window: 2026-08-24 to 2026-10-16.

Four views of the same eight weeks. The dated calendar, the epic timeline, the per-lane overrun, and the four milestones with what is not yet true at each one. Every date and number here comes off the confirmed meeting plan and the reviewed capacity arithmetic. Nothing on this page is re-derived.

Sprint boundaries fall on Wednesdays, so any week-numbered label is approximate at every boundary. Read the dates, not the week numbers.

4. Milestones. What is true, and what is not yet true

Bar the Shape readout, every date here is a demo Wednesday off the confirmed calendar. The two columns get the same width and the same type size, because the right-hand one is the half a client needs.

M0Shape readoutWed 2026-09-02

True at this date

  • The dated calendar and the sprint 1 ranked queue
  • The API contract and a running mock server
  • The relational schema drafted and reviewed
  • The CDK stack authored and synthesizing locally
  • The app shell running, with routing and the single brand theme
  • The Skia canvas engine started
  • The QA process standard and the tooling recommendation
  • The build host and pipeline decision
  • An auth and identity ADR

Not yet true

  • Nothing is deployed to AWS. Q17 and Q49 decide whose account and whose money
  • No signed build exists and nothing is in TestFlight
  • Nobody outside the delivery team has touched anything
  • No onboarding, no submit, no wall
M1Sprint 1 demoAnchorWed 2026-09-16

True at this date

  • A hosted API and a relational database in a real AWS environment
  • Sign in with email and password, on a device
  • Today's prompt on screen
  • The Skia canvas with the six inks, and you can draw on it
  • A manually signed build in TestFlight that named testers can install and open

In Rob's words: here is the app, it is hosted, it has a back end, it is in TestFlight and you can use it.

Not yet true

  • Submitting does not persist your drawing. The submit endpoint needs presigned upload (E04-F4, 3 backend-days) which needs media storage and delivery (E01-F6, 3 backend-days), and there are not 6 spare backend-days in a lane committed to 10 of 10. What you draw is not saved and nothing unlocks a wall
  • Guided onboarding screens 1 to 8 are not built, so first run is bare
  • No walls, no channels, and no other people's work to see
  • No invite path, so a second person cannot reach a wall
  • The build is signed by hand, not by CI
  • No push, no streaks, no moderation, no analytics
Gate Q5The Apple Developer account. If Q5 has not closed by 2026-09-02, E07-F1, E07-F3 and E07-F4 stall, there is no TestFlight build here, and the demo is a simulator screen recording rather than an app on a tester's phone.
Gate Q17 with Q49Whose AWS account, and whose money. The hosted API and the database in the left-hand column are exactly as conditional as the TestFlight build. Ranks 1 and 2 in the backend lane cannot start until these close and nothing else in that lane deploys behind them. If they are still open on 2026-09-02, "it is hosted, it has a back end" is not true at this demo, and what survives is the app running against E01-F5's mock server.
M2Sprint 2 demoWed 2026-09-30

True at this date

  • Guided onboarding, screens 1 to 8
  • Submit persists, with artwork in S3 behind CloudFront
  • Submit-to-unlock at the data layer, with its bypass test
  • Today's prompt served from the seeded curated set on the real fetch contract rather than the mock
  • An automated signed build out of CI
  • The QA automation harness running against the contract

Not yet true

  • Walls and channels are backend-first, so the social half is not demonstrable end to end
  • No reactions
  • No dashboard or stats card
  • Invites are still unfunded (Q8)
  • Still no push, streaks, moderation or analytics
M3Sprint 3 demoWed 2026-10-14

True at this date

  • The daily loop end to end for one person and their wall. Prompt, draw, submit, unlock, the wall grid and a response detail
  • Server-side channel isolation with its regression gate
  • Crash reporting with build traceability
  • The release gate applied at the demo rather than after it

Not yet true

  • No daily nudge, no moderation lane, no streaks, no analytics events. All four are orange band and none has a slot
  • No dashboard or stats card if E05-F5 stays cut
  • No invite path, so a second person still reaches a wall only by a route nobody has funded
  • Not submitted to the App Store, and whether submission is even in this phase is Q56
  • No iPad

The eight weeks end 2026-10-16, two working days after the M3 demo. There is no hardening sprint.
